# Triage Labels

The omskills category and state roles map directly to these GitHub labels.

| Kind | Canonical role | GitHub label | Meaning |
| --- | --- | --- | --- |
| Category | `bug` | `bug` | Something is broken |
| Category | `enhancement` | `enhancement` | New feature or improvement |
| State | `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| State | `needs-info` | `needs-info` | Waiting for more information |
| State | `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| State | `ready-for-human` | `ready-for-human` | Requires human implementation |
| State | `wontfix` | `wontfix` | Will not be actioned |

Every triaged issue should carry exactly one category role and one state role.
